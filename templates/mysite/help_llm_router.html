LLM router & OpenClaw-style routing

PolySaaS uses two layers so orchestration, ML Studio, DoseAI, and AI / Apps as Peers can share one routing policy without each feature hard-coding models.

The in-process router is meant to see the platform first: use llm_router.integrations.platform_link_map and platform_context_for_system_prompt so models know where OpenAPI / Swagger, RequestLog / ErrorLog, and passthrough APIs and admin screens live (prompts point at URLs; they do not auto-fetch the full schema).

Option 1 — In-process Django app (llm_router)

Python API inside the same Gunicorn process as the rest of Django.

  • Classify a prompt into buckets lite, standard, or heavy using length and simple keyword rules (optional task_hint such as code, analysis, agent).
  • Route to a provider + model per user tier (free, standard, premium, staff) via environment variables LLM_ROUTER_* (see .env.example in the repo).
  • Call Anthropic, xAI, or Gemini using the same API keys as AI Peers (ANTHROPIC_API_KEY, XAI_API_KEY, GEMINI_API_KEY).
  • Logs: logger llm_router.decisions records provider, model, tier, bucket, and a short prompt excerpt (never full prompts unless LLM_ROUTER_LOG_FULL_PROMPT=true).

Developer usage

from llm_router.router import route
from llm_router.providers import complete_chat

plan = route(prompt=user_text, task_hint="code", user_tier="standard")
text = complete_chat(
    plan,
    messages=[{"role": "user", "content": user_text}],
    system_prompt="You are a concise assistant.",
)

Smoke test (shell)

python manage.py llm_router_smoke --prompt "Hello" --tier standard
python manage.py llm_router_smoke --prompt "..." --call   # uses API quota

Option 2 — External service (openclaw_router/)

Separate FastAPI app in the repo with POST /v1/chat/completions (OpenAI-shaped JSON) for internal jobs: batch work, ops helpers, long tasks — not a public anonymous API.

  • Build with openclaw_router/Dockerfile; tune openclaw_router/config.yaml.
  • Deploy on Render as a private web service; set ANTHROPIC_API_KEY (extend main.py for more providers as needed).
  • See repo file documentation/deployment/render/OPENCLAW_ROUTER_OPTION2.md and openclaw_router/README.md.

Mattermost #router / #openclaw still go through AI Peers today; Option 2 is optional infrastructure you can wire later.
