PolySysMon Architecture

PolySysMon is built on a lightweight, GCP-native architecture. Agents collect data via SNMP, APIs, SQL, logs, or custom scripts — streaming securely to PubSub. Flexible scheduling drives processing, while multiple correlators apply your custom taxonomies for real-time anomaly detection. The intuitive TRex Web UI provides full visibility and control with minimal overhead.
