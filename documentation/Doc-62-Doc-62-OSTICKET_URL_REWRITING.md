# OSTicket URL Rewriting & Path Resolution Strategy

**Date**: October 23, 2025  
**Focus**: Deep dive into how URLs are rewritten for `/admin/osticket/` proxy

## Problem Statement

OSTicket is hosted at: `https://oliverenterprises.app.saasify.cloud/scp/`  
We want to proxy it through Django at: `http://localhost:8000/admin/osticket/`

The challenge: **OSTicket HTML, CSS, JavaScript, and AJAX requests reference URLs in many different formats that must all be rewritten transparently.**

## URL Categories & Rewriting Strategy

### Category 1: Absolute URLs

**Pattern**: `https://domain/path/to/resource`

**Examples from OSTicket HTML**:
```html
<a href="https://oliverenterprises.app.saasify.cloud/scp/index.php">Dashboard</a>
<link rel="stylesheet" href="https://oliverenterprises.app.saasify.cloud/scp/css/main.css">
<img src="https://oliverenterprises.app.saasify.cloud/scp/images/logo.png">
```

**Rewriting Rule**:
```
https://oliverenterprises.app.saasify.cloud/scp/* → /admin/osticket/*
https://oliverenterprises.app.saasify.cloud/* → /admin/osticket/*
```

**Implementation** (doseify_html stage 1):
```python
html = html.replace(
    'https://oliverenterprises.app.saasify.cloud/scp/',
    '/admin/osticket/'
)
html = html.replace(
    'https://oliverenterprises.app.saasify.cloud',
    '/admin/osticket'
)
```

**Why**: Absolute URLs are explicit and easy to find/replace with simple string operations

---

### Category 2: Root-Relative URLs

**Pattern**: `/path/to/resource` (starts with `/`, relative to domain root)

**Examples from OSTicket HTML**:
```html
<a href="/scp/login.php">Logout</a>
<link rel="stylesheet" href="/scp/css/style.css">
<script src="/scp/js/jquery.min.js"></script>
<img src="/scp/images/icon.png">
<form action="/scp/ajax.php" method="POST">
```

**Rewriting Rule**:
```
/scp/* → /admin/osticket/*
/scp → /admin/osticket
```

**Implementation** (doseify_html stage 2):
```python
# Form action="/scp/..." attributes
html = re.sub(
    r'action="([^"]*(?:/scp/)?[^"]*)"',
    lambda m: f'action="{rewrite_url(m.group(1))}"',
    html
)

# href="/scp/..." and src="/scp/..." attributes
html = re.sub(
    r'(href|src)="([^"]*(?:/scp/)?[^"]*)"',
    lambda m: f'{m.group(1)}="{rewrite_url(m.group(2))}"',
    html
)
```

**Helper function**:
```python
def rewrite_url(url):
    if not url:
        return url
    
    # Already rewritten or absolute Django URL
    if url.startswith('/admin/osticket/'):
        return url
    
    # Root-relative OSTicket URL
    if url.startswith('/scp/'):
        return url.replace('/scp/', '/admin/osticket/', 1)
    
    if url.startswith('/scp'):
        return url.replace('/scp', '/admin/osticket', 1)
    
    return url
```

**Why**: Regex allows us to find and update attribute values specifically

### Category 3: Relative URLs (Relative to Current Directory)

**Pattern**: `path/to/resource` or `./path/to/resource` (no leading `/`, relative to current dir)

**Examples from OSTicket HTML**:
```html
<!-- In /scp/index.php, these are relative to /scp/ -->
<link rel="stylesheet" href="css/main.css">
<!-- Resolves to: /scp/css/main.css -->

<script src="js/app.js"></script>
<!-- Resolves to: /scp/js/app.js -->

<img src="images/icon.png">
<!-- Resolves to: /scp/images/icon.png -->

<!-- In nested path /scp/admin/dashboard.php -->
<link rel="stylesheet" href="../css/main.css">
<!-- Resolves to: /scp/css/main.css -->

<script src="./app.js">
<!-- Resolves to: /scp/admin/app.js -->
```

**Challenge**: These are context-dependent and can't be reliably rewritten at HTML level because we don't know which page is being served.

**Solution**: Use `<base>` tag injection to set base URL

**Implementation** (not currently used, but option):
```python
html = html.replace(
    '<head>',
    '<head><base href="/admin/osticket/">'
)
```

**Why it works**: `<base>` tells browser to resolve all relative URLs against specified base

**Why we don't use it currently**: 
- Some OSTicket JavaScript might reference resources absolutely
- Better approach: JavaScript interceptor (see Category 4)

---

### Category 4: Dynamic URLs (Generated by JavaScript)

**Pattern**: URLs created at runtime by JavaScript code

**Examples from OSTicket JavaScript**:
```javascript
// Inline JavaScript
$.ajax({url: 'ajax.php', ...});
$.ajax({url: '/scp/ajax.php', ...});

// Form submission
$('form').submit(function() {
    var action = $(this).attr('action');  // Could be 'ajax.php' or '/scp/ajax.php'
    $.post(action, data, ...);
});

// Dynamic link generation
var ticketUrl = 'ticket.php?id=' + ticketId;
window.location = ticketUrl;
```

**Challenge**: These URLs are created in JavaScript runtime, not in HTML - can't rewrite them with HTML string manipulation

**Solution**: JavaScript interceptor

**Implementation** (doseify_html stage 4 - jQuery AJAX Override):
```python
# Inject JavaScript that intercepts all AJAX calls
js_interceptor = """
<script>
window.__originalUrl = window.location.href;

// Override jQuery.ajax to rewrite URLs
if (window.jQuery) {
    var originalAjax = jQuery.ajax;
    jQuery.ajax = function(settings) {
        // Rewrite URL
        var url = settings.url;
        if (url) {
            // Rewrite /scp/ paths
            url = url.replace('https://oliverenterprises.app.saasify.cloud/scp/', '/admin/osticket/')
                     .replace('https://oliverenterprises.app.saasify.cloud', '/admin/osticket')
                     .replace(/^\\/scp\\//, '/admin/osticket/')
                     .replace(/^\\/scp$/, '/admin/osticket')
                     .replace(/^ajax\\.php/, '/admin/osticket/ajax.php')
                     .replace(/^login\\.php/, '/admin/osticket/login.php');
            
            settings.url = url;
        }
        
        // Call original ajax
        return originalAjax.call(jQuery, settings);
    };
}
</script>
"""
```

**Why this works**:
1. Before jQuery makes AJAX request, our interceptor runs
2. Intercepts request URL
3. Rewrites `/scp/` → `/admin/osticket/`
4. Passes modified request to original jQuery.ajax
5. Browser sends request to Django, not OSTicket

**Specific cases handled**:
- `'ajax.php'` → `/admin/osticket/ajax.php` (relative)
- `'/scp/ajax.php'` → `/admin/osticket/ajax.php` (root-relative)
- `'https://oliverenterprises.app.saasify.cloud/scp/ajax.php'` → `/admin/osticket/ajax.php` (absolute)

### Category 5: XMLHttpRequest (Non-jQuery AJAX)

**Pattern**: Direct `XMLHttpRequest` calls without jQuery

**Examples from JavaScript**:
```javascript
var xhr = new XMLHttpRequest();
xhr.open('POST', '/scp/ajax.php', true);
xhr.send(formData);
```

**Solution**: Override XMLHttpRequest.prototype.open

**Implementation** (doseify_html stage 3):
```python
js_interceptor += """
<script>
var originalXHROpen = XMLHttpRequest.prototype.open;
XMLHttpRequest.prototype.open = function(method, url) {
    // Rewrite URL before opening
    url = url.replace(/^\\/scp\\//, '/admin/osticket/')
             .replace(/^\\/scp$/, '/admin/osticket');
    
    return originalXHROpen.call(this, method, url, ...arguments);
};
</script>
"""
```

### Category 6: fetch() API (Modern JavaScript)

**Pattern**: Modern `fetch()` API calls

**Examples from JavaScript**:
```javascript
fetch('/scp/api.php?action=get_tickets')
    .then(response => response.json())
    .then(data => console.log(data));
```

**Solution**: Override window.fetch

**Implementation** (doseify_html stage 5):
```python
js_interceptor += """
<script>
var originalFetch = window.fetch;
window.fetch = function(url, options) {
    // Rewrite URL before fetching
    url = url.replace(/^\\/scp\\//, '/admin/osticket/')
             .replace(/^\\/scp$/, '/admin/osticket');
    
    return originalFetch.call(window, url, options);
};
</script>
"""
```

### Category 7: Link Clicks & Navigation

**Pattern**: User clicks links that navigate to OSTicket pages

**Examples from HTML**:
```html
<a href="tickets.php?id=123" onclick="loadTicket(this); return false;">Ticket #123</a>
<a href="/scp/index.php">Dashboard</a>
```

**Challenge**: Sometimes links have onclick handlers that manipulate URLs

**Solution**: jQuery click interceptor + form interception

**Implementation** (doseify_html stage 6):
```python
js_interceptor += """
<script>
// Delay setup until jQuery available
setTimeout(function() {
    if (window.jQuery) {
        // Intercept all form submissions
        jQuery(document).on('submit', 'form', function(e) {
            var action = jQuery(this).attr('action');
            if (action && !action.startsWith('/admin/osticket')) {
                action = action.replace(/^\\/scp\\//, '/admin/osticket/')
                               .replace(/^\\/scp$/, '/admin/osticket');
                jQuery(this).attr('action', action);
            }
        });
        
        // Intercept link clicks
        jQuery(document).on('click', 'a', function(e) {
            var href = jQuery(this).attr('href');
            if (href && (href.includes('/scp/') || href.includes('login.php'))) {
                e.preventDefault();
                window.location = href.replace(/^\\/scp\\//, '/admin/osticket/')
                                      .replace(/^\\/scp$/, '/admin/osticket');
            }
        });
    }
}, 100);
</script>
"""
```

### Category 8: Redirect URLs in AJAX Responses

**Pattern**: JSON responses containing redirect URLs

**Examples from OSTicket AJAX Response**:
```json
{
    "status": "success",
    "redirect": "/scp/tickets.php?id=456",
    "message": "Ticket created"
}
```

**Challenge**: These are in response bodies, not HTML attributes

**Solution**: jQuery AJAX success interceptor

**Implementation** (doseify_html - response interception):
```python
js_interceptor += """
<script>
if (window.jQuery) {
    jQuery.ajaxSetup({
        complete: function(xhr, status) {
            // Intercept successful AJAX responses
            if (status === 'success' || status === 'nocontent') {
                var data = xhr.responseJSON;
                if (data && data.redirect) {
                    // Rewrite redirect URL
                    data.redirect = data.redirect
                        .replace(/^\\/scp\\//, '/admin/osticket/')
                        .replace(/^\\/scp$/, '/admin/osticket');
                }
            }
        }
    });
}
</script>
"""
```

**Better implementation** - wrap success callback:
```python
js_interceptor += """
<script>
if (window.jQuery) {
    var originalAjax = jQuery.ajax;
    jQuery.ajax = function(settings) {
        var originalSuccess = settings.success;
        
        // Wrap success callback to intercept response
        settings.success = function(data, status, xhr) {
            // Intercept and rewrite redirect URLs
            if (data && data.redirect) {
                data.redirect = data.redirect
                    .replace('https://oliverenterprises.app.saasify.cloud/scp/', '/admin/osticket/')
                    .replace(/^\\/scp\\//, '/admin/osticket/');
            }
            
            // Call original success handler
            if (originalSuccess) {
                return originalSuccess.call(this, data, status, xhr);
            }
        };
        
        return originalAjax.call(jQuery, settings);
    };
}
</script>
"""
```

## Edge Cases & Special Handling

### Edge Case 1: Query Strings & Fragments
```
URL: /scp/tickets.php?id=123&status=open#section1
↓
Rewrite: /admin/osticket/tickets.php?id=123&status=open#section1
```

**Handling**: Simple string/regex replace preserves query strings and fragments

### Edge Case 2: URL Encoding
```
URL: /scp/search.php?q=hello%20world&filter=open
↓
Rewrite: /admin/osticket/search.php?q=hello%20world&filter=open
```

**Handling**: String replace doesn't decode/encode, preserves original encoding

### Edge Case 3: Mixed Protocols
```
URL: http://oliverenterprises.app.saasify.cloud/scp/... (HTTP not HTTPS)
↓
Rewrite: /admin/osticket/...
```

**Handling**: Our replace catches both protocols

### Edge Case 4: Domain Variations
```
Possible URLs:
- https://oliverenterprises.app.saasify.cloud/scp/
- https://saasify.cloud/scp/
- https://app.saasify.cloud/scp/
```

**Challenge**: Different domain might be served in different contexts

**Solution**: Replace all known domains and also replace `/scp/` paths

## Performance Optimization

### Current Performance
- String replacements: O(n) where n = HTML size
- Regex operations: O(n) for each pattern
- JavaScript injection: Adds ~5KB to page
- Total doseify time: 5-50ms for typical 100KB HTML

### Optimization Ideas
1. **Regex compilation**: Pre-compile regex patterns outside function
2. **Caching**: Cache doseified content if same URL requested multiple times
3. **Async processing**: Process HTML asynchronously if timeout is concern
4. **Streaming**: Stream response to browser while processing

### Implementation
```python
# Pre-compile regex patterns (outside function)
REGEX_PATTERNS = {
    'form_action': re.compile(r'action="([^"]*)"'),
    'href_src': re.compile(r'(href|src)="([^"]*)"'),
    ...
}

# Reuse compiled patterns in doseify_html
html = REGEX_PATTERNS['form_action'].sub(..., html)
```

$.ajax = function(settings) {

### Browser DevTools Network Tab
1. Open F12 → Network tab
2. Click link in OSTicket
3. Look at request URL - should be `/admin/osticket/...`

1. Right-click → View Source
2. Search for `/scp/` - should find few/none (mostly rewritten)
