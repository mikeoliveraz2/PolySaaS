## How Passthrough Works
- For unmatched requests:
  1. Middleware checks the current tenant from session.
  2. Looks up PassThroughEndpoint for that tenant.
  3. If found, forwards the request to the configured external URL.
  4. If not found, forwards to the default echo test endpoint (`http://localhost:5000/echo`).
