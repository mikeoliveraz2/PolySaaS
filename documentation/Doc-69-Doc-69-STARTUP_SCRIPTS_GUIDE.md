# PolySaaS Startup & Backup Guide

**Last Updated**: February 22, 2026

---

## .\go.ps1 — Primary Launcher

The single script to start everything. Run from `E:\PolySaaS`.

```powershell
.\go.ps1
```

### What It Does (in order)

1. **Daily Source Backup** — first thing, before anything else
2. **Activates venv** and loads `.env`
3. **Starts services** (each in its own PowerShell window, skipped if already running):
   - Monitor Logger on port 5000
   - PolySniffer on port 5002
   - PolySysMon (Tomcat Docker) on port 9001
   - Liferay CE (Docker Compose) on port 8181
4. **Starts Django** on port 8000 (foreground, blocks terminal)

### Service URLs

| Service | URL |
|---------|-----|
| Django | http://localhost:8000 |
| Monitor Logger | http://localhost:5000 |
| PolySniffer | http://127.0.0.1:5002 |
| Liferay CE | http://localhost:8181 |
| PolySysMon | http://localhost:9001 |
| Nextcloud | http://localhost:8888 |

## Daily Source Backup

Runs automatically on first `.\go.ps1` execution each day. Only one backup per day — subsequent runs that day are skipped.

### Location & Naming

- **Destination**: `E:\backups\`
- **Filename**: `polysaas-backup-YYYY-MM-DD_HHmmss.zip`
- **Example**: `polysaas-backup-2026-02-22_091530.zip`

### What IS Backed Up

All source files in the workspace, including:

- All Python source (`.py`), templates, static files
- `requirements.txt`, `manage.py`, `go.ps1`
- Configuration files (`.env`, `*.yml`, `*.json`, `*.toml`)
- Documentation (`*.md`)
- Migration files
- Docker Compose files
- Chrome extension files (`polysniffer-chrome-extension/`)

### What Is NOT Backed Up (Excluded)

| Excluded | Reason |
|----------|--------|
| `venv/` | Reconstructable via `pip install -r requirements.txt` |
| `node_modules/` | Reconstructable via `npm install` |
| `.git/` | Managed separately by Git |
| `__pycache__/`, `*.pyc` | Auto-generated bytecode |
| `media/` | User uploads (backed up separately) |
| `large_files_backup/` | Already a backup directory |
| `var/` | Runtime data (static_root, etc.) |
| `.mypy_cache/` | Type checker cache |
| `.pytest_cache/` | Test runner cache |
| `*.egg-info` | Package metadata |

### Restore Procedure

```powershell
# Extract a backup to a temporary location
Expand-Archive -Path "E:\backups\polysaas-backup-2026-02-22_091530.zip" -DestinationPath "E:\restore-temp"

# Then copy specific files as needed, or replace the whole workspace
```

## Troubleshooting

### "venv not found"
Run from project root: `cd E:\PolySaaS` then `.\go.ps1`

### Port already in use
```powershell
Get-Process python -ErrorAction SilentlyContinue | Stop-Process -Force
.\go.ps1
```

### Django won't start (DB error)
Ensure PostgreSQL is running on port 5433 and `.env` has the correct `DOSE_DB_PASSWORD`.

### Docker services won't start
Ensure Docker Desktop is running before executing `.\go.ps1`.
