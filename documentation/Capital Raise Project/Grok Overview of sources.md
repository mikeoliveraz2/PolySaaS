### 1. Angel Investors via AngelList
**What They Look For:** Vision-driven SaaS with 90%+ gross margins potential; strong team/founder commitment; MVP traction (e.g., prototype, user feedback). Angels here (e.g., SaaS syndicate leads) prioritize scalable software over hardware. Expect 20-40% close rate if networked well; focus on ROI (30-40%) and exit path.

**Tailored Submission Structure (Pitch Deck + Outreach):**
- **Length:** 10-15 slide deck + 1-page teaser email.
- **Key Sections:**
  1. Problem/Solution: Highlight SaaS pain point (e.g., "Streamlines MVP workflows for remote teams") + MVP demo screenshot.
  2. Market Opportunity: $X TAM for SaaS niche; early validation (e.g., 50 beta sign-ups).
  3. Traction: MVP metrics (e.g., 20% MoM user growth); no revenue needed but pilot LOIs help.
  4. Team: Your SaaS dev experience; why you're committed (e.g., bootstrapped MVP).
  5. Ask: $15k SAFE at $5M cap for MVP polish/marketing.
  6. Exit/ROI: Comparable SaaS exits (e.g., "Like [similar tool] acquired for 10x").
- **Process:** Build AngelList profile; network via intros (not cold emails). Launch syndicate if 20-40% committed. Timeline: 2-4 weeks.

### 2. Wefunder Equity Crowdfunding
**What They Look For:** Community-engageable SaaS MVP; clear equity offer (e.g., SAFE); traction like MVP waitlist. 80%+ success rate for prepared campaigns; emphasize de-risked MVP (e.g., early users).

**Tailored Submission Structure (Campaign Page + Form C):**
- **Length:** 5-min video + 1,000-word page; SEC Form C (auto-generated).
- **Key Sections:**
  1. Hook Video: Founder pitch MVP (e.g., "Watch our SaaS automate [task] in 30s").
  2. Story/Traction: MVP journey (e.g., "Built v1 in 3 months; 100+ waitlist").
  3. Use of Funds: $15k for user acquisition/server scaling.
  4. Equity Terms: SAFE at $4M cap; min. $100 investment.
  5. Risks/Milestones: Address SaaS churn; roadmap to $10k MRR.
- **Process:** Submit via portal (company docs, terms); Wefunder reviews (1-2 weeks). Promote via network for 30% Day 1 goal. Fees: 7.5% if successful. Timeline: 1 month launch.

### 3. Republic Equity Crowdfunding

**Tailored Submission Structure (Application + Campaign):**
- **Length:** Online form + pitch page/video.
- **Key Sections:**
  1. Business Overview: SaaS MVP summary (e.g., "AI tool for MVP feedback loops").
  2. Traction/Validation: MVP stats (e.g., pilot conversions); market fit evidence.
  3. Growth Plan: $18k for beta launch/marketing; 3-6 month milestones.
  4. Team/Equity: Founder bios; SAFE details (e.g., $3M cap).
  5. Community Impact: How SaaS empowers users (e.g., indie devs).
- **Process:** Apply at republic.com/apply (docs review, 2-4 weeks). Launch campaign; promote for momentum. No upfront fees; 6-8% if funded. Timeline: 4-6 weeks.
