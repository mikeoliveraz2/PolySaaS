## How PolySaaS Works with Liferay

**PolySaaS + Liferay — Intelligent, Zero-Code Extension**

1. Liferay user performs an action (form submit, page edit, workflow approval)
2. Atomic Service detects the trigger → publishes event to Pub/Sub
3. Connected apps & AI peers react in real time (Mattermost notification, Odoo record update, Gemini summary)
4. All changes logged to BigQuery for analytics & audit
5. No Liferay code changes required — only configuration
