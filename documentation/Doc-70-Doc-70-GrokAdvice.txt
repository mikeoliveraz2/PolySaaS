Adding a Dark Mode Toggle to Light Mode in Django Jazzmin Admin
Django Jazzmin provides built-in support for themes, including light and dark variants (e.g., "flatly" for light and "darkly" for dark). However, it doesn't include a built-in toggle button out of the box—instead, it can automatically respect the user's device/OS preference for dark mode (via prefers-color-scheme). To add a manual toggle button that switches between light and dark modes and persists the user's choice (overriding the device preference), you'll need to:

Store the user's theme preference in the database (e.g., as a User profile field).
Configure Jazzmin to dynamically select the theme based on the user's preference.
Add a toggle button to the admin UI using Jazzmin's usermenu_links (for the top-right user dropdown) or by extending the template with custom JavaScript/CSS.
Handle the toggle logic with a simple AJAX call or form submission to update the preference.
This approach ensures the toggle works seamlessly without reloading the entire page (using JavaScript). Below, I'll walk you through the implementation step by step, with example code.

Step 1: Add a Theme Preference Field to Your User Model
Use a one-to-one profile model to store the preference without altering Django's built-in User model. Create or update models.py in your main app (e.g., myapp/models.py):

python
from django.db import models
from django.contrib.auth.models import User

class UserProfile(models.Model):
    user = models.OneToOneField(User, on_delete=models.CASCADE)
    dark_mode = models.BooleanField(default=False)  # True for dark, False for light

    def __str__(self):
        return f"{self.user.username}'s Profile"

Step 2: Create a View to Toggle the Preference
Add a view to handle the toggle (via POST). In views.py (e.g., myapp/views.py):

python
from django.shortcuts import get_object_or_404, redirect
from django.contrib.auth.decorators import login_required
from django.http import JsonResponse
from .models import UserProfile

@login_required
def toggle_theme(request):
    profile, created = UserProfile.objects.get_or_create(user=request.user)
    profile.dark_mode = not profile.dark_mode
    profile.save()
    return JsonResponse({'dark_mode': profile.dark_mode})
Add the URL pattern in urls.py (e.g., myapp/urls.py):

python
from django.urls import path
from . import views

urlpatterns = [
    # ... your other URLs
    path('toggle-theme/', views.toggle_theme, name='toggle_theme'),
]
Include this in your project's main urls.py:

python
from django.urls import include, path

    # ... other patterns

Step 3: Configure Jazzmin Settings
In your project's settings.py, set up Jazzmin to use dynamic themes based on the user's preference. We'll use a custom context processor to inject the theme choice.

First, add a context processor in a new file context_processors.py (e.g., in myapp/context_processors.py):

python
from .models import UserProfile

def jazzmin_theme(request):
    if request.user.is_authenticated:
        profile, _ = UserProfile.objects.get_or_create(user=request.user)
        theme = 'darkly' if profile.dark_mode else 'flatly'
    else:
        theme = 'flatly'  # Default to light for anonymous users
    return {'jazzmin_theme': theme}
Add it to TEMPLATES in settings.py:

python
TEMPLATES = [
    {
        'BACKEND': 'django.template.backends.django.DjangoTemplates',
        'DIRS': [],
        'APP_DIRS': True,
        'OPTIONS': {
            'context_processors': [
                # ... Django's default ones
                'myapp.context_processors.jazzmin_theme',  # Add this
            ],
        },
    },
]
Now, update your Jazzmin settings in settings.py to use the dynamic theme:

python
JAZZMIN_SETTINGS = {
    # ... your other Jazzmin settings
    "usermenu_links": [
        {
            "name": "Toggle Theme",  # This will add a link to the user menu; we'll override it with JS for the button
            "url": "javascript:void(0)",  # Placeholder; JS will handle the click
            "new_window": False,
            "icon": "fas fa-moon",  # FontAwesome icon for moon (dark mode)
        }
    ],
    "ui_tweaks": {
        "theme": "{{ jazzmin_theme }}",  # Dynamic: 'flatly' or 'darkly'
    },
}
Note: The {{ jazzmin_theme }} uses the context processor to dynamically set the theme per request. Jazzmin will load the appropriate Bootstrap theme CSS (from Bootswatch).

Step 4: Add the Toggle Button with JavaScript
To make it a proper toggle button (not just a link), add custom JS and CSS via Jazzmin's custom_js and custom_css settings. Create these files in your static folder (e.g., static/admin/css/theme-toggle.css and static/admin/js/theme-toggle.js).

    cursor: pointer;

    transform: rotate(180deg);  /* Rotate sun to moon or vice versa */
}
custom_js (theme-toggle.js):

javascript
document.addEventListener('DOMContentLoaded', function() {
    // Find the toggle button in the user menu (adjust selector if needed)
    const toggleBtn = document.querySelector('.usermenu a[href="javascript:void(0)"]');  // Targets the usermenu link we added
    if (!toggleBtn) return;

    // Load initial state from a data attribute or assume light (you can enhance this)
    const isDark = document.body.classList.contains('dark-mode');  // Or fetch via AJAX if needed
    toggleBtn.classList.toggle('dark-mode', isDark);
    toggleBtn.innerHTML = isDark ? '<i class="fas fa-sun"></i> Light Mode' : '<i class="fas fa-moon"></i> Dark Mode';

    toggleBtn.addEventListener('click', function(e) {
        e.preventDefault();
        const currentDark = this.classList.contains('dark-mode');
        const newMode = !currentDark;

        // AJAX call to toggle
        fetch('/admin/toggle-theme/', {  // Adjust URL if your admin prefix differs
            method: 'POST',
            headers: {
                'Content-Type': 'application/json',
                'X-CSRFToken': document.querySelector('[name=csrfmiddlewaretoken]').value,  // Django CSRF
            },
        })
        .then(response => response.json())
        .then(data => {
            if (data.dark_mode !== currentDark) {
                // Reload page to apply new theme (simple way; for no-reload, you'd swap CSS links dynamically)
                window.location.reload();
            }
        })
        .catch(error => console.error('Toggle failed:', error));
    });
});

Step 5: Testing and Enhancements
Restart your server and log in to /admin/.
The toggle should appear in the top-right user menu. Clicking it updates the preference and reloads with the new theme.
Initial load respects the stored preference (light by default).
Enhancements:
For no page reload: Dynamically swap the Bootstrap CSS link in JS (e.g., change href from flatly.min.css to darkly.min.css).
Auto-detect device preference on first visit: In the context processor, check request.META.get('HTTP_SEC_CH_PREFERS_COLOR_SCHEME', 'light') or use JS window.matchMedia.
If you want the toggle outside the user menu (e.g., as a fixed button), extend Jazzmin's base template via JAZZMIN_SETTINGS["custom_template"].
