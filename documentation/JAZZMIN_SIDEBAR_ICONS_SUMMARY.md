# Jazzmin Sidebar Icons Summary

This document summarizes the FontAwesome icons set for sidebar models in Jazzmin via `JAZZMIN_SETTINGS`.

## How Icons Are Set
- Icons are set in the `icons` dictionary in `JAZZMIN_SETTINGS`.
- Format: `"app_label.model_name": "fa-class"`
- Example: `"alerts.notifications": "fas fa-bell"`
