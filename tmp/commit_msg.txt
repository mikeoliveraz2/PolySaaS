Add Playwright-based HubSpot session provisioner (bypasses bot detection)

- Install playwright==1.61.0 + greenlet + pyee into requirements.txt
- Add provision_hubspot_session management command: launches headless
  Chromium (real browser TLS fingerprint) to log into app.hubspot.com,
  extracts all session cookies, persists to TenantApp.extra_config via
  HubspotSessionService.persist_web_cookies() — same Mattermost/Odoo pattern
- Fix WEB_COOKIE_TTL_SECONDS: 1800s (30min) -> 7 days so Playwright-
  provisioned cookies survive server idle periods without re-login
- HubspotSessionService already reads hs_web_cookies from TenantApp.extra_config
  and forwards them on all proxied requests — no passthrough handler changes needed
- Supports --headful flag for 2FA/CAPTCHA debugging
- Supports --validate-only to probe stored cookies against HubSpot portal API

Usage: python manage.py provision_hubspot_session olient --email ... --password ...
Note: after pip install, run: python -m playwright install chromium
